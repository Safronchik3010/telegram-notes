# Telegram Notes

Skill для Claude Code.

**Цикл:** ВЗЯТЬ (Telegram API) → ОБРАБОТАТЬ (классификация на идеи и задачи) → ПОЛОЖИТЬ (ideas.md, tasks.md)

## Как работает

1. `fetch.py` берёт новые сообщения из Telegram-бота через getUpdates
2. Фильтрует только текстовые сообщения (без голосовых, фото и т.д.)
3. Классифицирует каждое сообщение:
   - **Задача** — содержит слова: сделать, купить, написать, позвонить, отправить, созвониться, встретиться, подготовить, проверить, напомнить, todo, task
   - **Идея** — всё остальное
4. Дописывает в `tasks.md` или `ideas.md` с меткой времени: `[YYYY-MM-DD HH:MM]`
5. Сохраняет offset в `.offset` чтобы не обрабатывать старые сообщения повторно

## Требования

```bash
export TELEGRAM_BOT_TOKEN=your_token_here
```

## Запуск

```bash
python3 ~/datapeople/telegram-notes/fetch.py
```

Или через Claude Code skill:
```
/telegram-notes
```
